# Talks & Podcasts

## MCP Is Less Software Engineering And More Social Engineering

**The Effortless Podcast** • April 2025

Featured on The Effortless Podcast with Dheeraj Pandey (former CEO of Nutanix, current CEO of DevRev). We discussed AI workflows, federated vs. integrated systems, Python for LLMs, and enterprise automation.

### Key Topics Covered

- **AI's Evolution:** Function calling has revolutionized how LLMs interact with the world by enabling real-time data retrieval and task execution through API calls and external systems
- **Federated vs. Integrated Systems:** Trade-offs between leaving data in legacy systems vs. centralizing for better performance and consistency
- **CodeAct's Potential:** Using Python code execution instead of traditional tool calls to create more flexible, efficient LLM agents
- **AI for Enterprises:** Making AI-driven workflow automation accessible to companies without deep technical expertise
- **Future of AI Agents:** Enhancing ability to generate and execute code for more powerful and autonomous systems
